# 链路盒子 v1.4.0

这一版主要整理内部结构，macOS 与 Windows 的规则集中到同一处并用同一组样例核对，日常使用方式不变。

- 预期出口 IP 按地址比较。同一个 IPv6 地址的不同写法不再被误判为不符。
- Windows 测速和网络检查使用开始时的预期出口 IP，中途修改设置从下一轮开始生效。
- Windows 测速设置的输入校验与 macOS 一致，填写有误时提示具体字段。
- 管理节点按完整名称区分节点。名称看起来相同、写法不同的两个节点会分别显示和勾选。
- Clash 控制接口返回错误时只显示状态码和简短说明，不再显示返回内容。
- 发布前自动核对版本号和安装包内必需的文件。

## 下载

- Apple Silicon Mac：`linkbox-macos-arm64.zip`，解压后将「链路盒子」拖到 Applications。
- Windows 10/11 x64：`linkbox-windows-x64.zip`，完整解压后运行 `LinkBox.exe`。
- 使用对应的 `.sha256` 文件核对下载完整性。

升级时替换程序文件即可，已保存的勾选名单和连接设置会继续使用。运行仍需 Clash Verge Rev。Mac 安装包使用 ad-hoc 签名，未经 Apple 公证。Windows 安装包暂无发行商代码签名。
