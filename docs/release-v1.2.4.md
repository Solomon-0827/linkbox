# 链路盒子 v1.2.4

- 将「每小时测速」改为「动态测速」，保留原开关；点击旁边的齿轮可保存测速间隔、并发量、自动换节点选项及排序依据。
- 自动换节点默认关闭。启用后，仅在动态测速完成、候选节点通过美国静态出口验证且优势足够明显时切换；手动测速不会换节点。
- 节点选择对话框支持一键更新订阅：移除已失效的订阅和节点，新增节点仍由用户手动选择。

Apple Silicon Mac 下载 `linkbox-macos-arm64.zip`。Windows x64 下载 `linkbox-windows-x64.zip`，完整解压后运行 `LinkBox.exe`。可用对应的 `.sha256` 文件核对下载。升级保留原有 Clash Verge 配置和本机数据。公开安装包不包含订阅或代理凭据。
