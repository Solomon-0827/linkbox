# 链路盒子 v1.3.0

macOS 与 Windows 现在使用相同的订阅整理规则。

- 「管理节点」保存勾选名单。多个订阅有同名节点时会同时展示，勾选其中一个会取消另一个。测速和切换都使用所选订阅的节点。
- 更新订阅时自动移除失效节点，新增节点可在管理节点中手动勾选。升级后若还没有勾选名单，会先同步订阅，再按当前中转入口组初始化。
- 当前入口失效或被取消勾选时，自动使用名单中按设置指标最快的节点。没有可用测速结果时选名单第一项。若名单中已没有可用节点，更新取消。
- 修复 Windows 动态测速设置无法打开的问题。测速遇到状态读取错误时，会等正在运行的任务退出后再释放操作锁。
- 修复 macOS 安装包缺少 Net.Coffee 解析文件的问题。固定出口使用域名或不同服务器地址时，全链路测速支持用本机配置的预期公网 IP 核验结果。

## 下载

- Apple Silicon Mac：`linkbox-macos-arm64.zip`，解压后将「链路盒子」拖到 Applications。
- Windows 10/11 x64：`linkbox-windows-x64.zip`，完整解压后运行 `LinkBox.exe`。
- 使用对应的 `.sha256` 文件核对下载完整性。

升级时替换程序文件即可，已保存的勾选名单和连接设置会继续使用。运行仍需 Clash Verge Rev。Mac 安装包使用 ad-hoc 签名，未经 Apple 公证。Windows 安装包暂无发行商代码签名。
