# 链路盒子 v1.2.0

Windows 同步当前 Mac 版的紧凑浅色布局与节点管理功能。

- 从 Clash Verge 自动读取订阅，左右分组选择节点，支持全选、清空和当前节点保护。
- 在列表中多选移除节点；只调整候选列表，不自动切换当前入口。
- 更新订阅保留当前中转与美国静态出口，保存前校验配置，异常时回退文件。
- 全链路测速同时测入口延迟，最多 5 条并发；测速图标原位旋转，完成后显示最快节点。
- 状态刷新、更新订阅、节点管理和编辑均采用就近图标；悬浮变色并显示功能提示。
- 网络检查与 Net.Coffee 合并到菜单；检查结果按需下载，不再自动保存报告。
- 保留每小时自动测速、最后测速时间、后台托盘和双击切换。

## 下载

- Apple Silicon Mac：`linkbox-macos-arm64.zip`，解压后将 app 放入 Applications。
- Windows 10/11 x64：`linkbox-windows-x64.zip`，完整解压文件夹后运行 `LinkBox.exe`。
- `.sha256` 文件用于校验下载完整性。

升级仅替换程序文件，保留本机订阅、节点筛选和代理设置。程序仍需要 Clash Verge Rev；公开安装包不含代理账号或订阅凭据。

Mac 使用 ad-hoc 签名、未经 Apple 公证；Windows 暂无发行商代码签名。自动测试与构建不能代替 Windows 实机网络验收，请在目标机器上使用“检查网络”核对 TUN、IPv6 和 Claude Code 的当前连接。
