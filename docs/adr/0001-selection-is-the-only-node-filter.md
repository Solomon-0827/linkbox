# 0001 勾选名单决定中转节点

## 背景

两个平台曾根据不同的规则保留节点，同名节点也可能让测速使用另一份订阅的配置。

## 决策

移除屏蔽名单，直接丢弃旧屏蔽数据，无需迁移、备份或提示。每个已勾选的名称只有一个节点归属。整理时以勾选名单和最新订阅的交集为准，实时中转入口组用于检测外部变化。首次缺少勾选名单时先同步订阅，再按订阅和节点的展示顺序，从实时组中为每个名字选定第一个匹配项。两个实现通过同一套 JSON 用例验证整理计划。

## 影响

当前入口必须在整理后的名单中。若被取消或已失效，优先采用所属订阅最近一轮可用的测速结果，按配置的指标选最快节点，缺少结果时按管理节点顺序取首项。旧结果只有在名称归属无歧义时才用于排序。配置先校验并加载，再按需切换和核对链路，无需提示或触发测速。若名单为空，整次更新取消。
